    API para desarrolladores

    Integra la conversión en tus sistemas con una API REST documentada.

    Planes

    Empieza gratis. Mejora cuando lo necesites.

    API

    Documentación interactiva en /docs. Ejemplos:

    # PDF → Markdown (descarga .md directamente)
curl -H "X-API-Key: TU_CLAVE" -F file=@informe.pdf -F output=md \
     /api/convert/pdf-to-md -o informe.md

# Markdown → PDF
curl -H "X-API-Key: TU_CLAVE" -F file=@notas.md -F theme=clasico \
     /api/convert/md-to-pdf -o notas.pdf
